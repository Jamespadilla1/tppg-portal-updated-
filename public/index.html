How the portal works

One hierarchy, five dashboards, full visibility.

Every application starts as an agent applicant. An admin reviews it and places you in the structure.

  1. A

    Admin

    Full org chart. Approves applicants, manages listings and commission releases.

  2. UM

    Unit Manager

    4.0% base rate. Oversees a downward team and adds clients directly.

  3. SM

    Sales Manager

    3.25%–3.7% by rank. Can report to a unit manager, or stand solo.

  4. TL

    Team Leader

    3.0% base rate. Manages a team of agents and records own sales.

  5. AG

    Agent

    2.0%–2.75% by rank. Reports to a team leader, sales manager, or unit manager.

Gross = TCN × Rate% Rate set per person, per rank, by the admin
Net = Gross − 10% WT − 3% PT Auto-computed on every recorded sale
