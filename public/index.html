How The Portal Works

One hierarchy, five dashboards, full visibility

Every application starts as an agent applicant — Admin reviews and places you into the structure.

A

Admin

Full org chart. Approves applicants, manages listings & commission releases.

UM

Unit Manager

4.0% base rate. Oversees a downward team, adds clients directly.

SM

Sales Manager

3.25%–3.7% by rank. Can report to a UM, or stand solo.

TL

Team Leader

3.0% base rate. Manages a team of agents, records own sales.

AG

Agent

2.0%–2.75% by rank. Reports to a TL, SM, or UM directly.

Gross = TCN × Rate%
Rate set per person, per rank, by Admin
Net = Gross − 10% WT − 3% PT
